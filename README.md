# Quick Calculator

Microsoft Edge のツールバーからすぐに使える、Windows 標準電卓風のシンプルな電卓拡張機能です。外部通信を行わず、権限も要求しません。

## アイコン

アイコンは `icons/` にまとめています。

| ファイル | 用途 |
| --- | --- |
| `icon.svg` | デザイン原本（48px 以上・ポップアップのタイトル・favicon） |
| `icon-small.svg` | 小サイズ用の簡略版（16〜32px 用 PNG の元データ） |
| `icon-16/24/32/48/128.png` | 拡張機能一覧・ツールバーボタン用 |
| `favicon.ico` | favicon の SVG 非対応環境向けフォールバック |

拡張機能のアイコンは PNG のみ対応のため、SVG から書き出した PNG を同梱しています。
デザインを変更する場合は SVG を編集し、同じサイズで PNG を書き出し直してください。

## Edge への読み込み

1. Edge で `edge://extensions/` を開きます。
2. 左側の **開発者モード** をオンにします。
3. **展開して読み込み** をクリックし、このフォルダーを選択します。
4. ツールバーの拡張機能一覧から **Quick Calculator** を開きます。

## キーボード操作

- 数字、`.`、`+`、`-`、`*`、`/`、`%`
- `Enter` または `=`: 計算
- `Backspace`: 1文字削除
- `Delete`: CE
- `Escape`: C
