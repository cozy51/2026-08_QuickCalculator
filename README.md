# Quick Calculator

Microsoft Edge のツールバーからすぐに使える、Windows 標準電卓風のシンプルな電卓拡張機能です。外部通信は行いません。`Paste`機能のため、クリップボードの読み取り権限だけを使用します。

構成ファイルはすべてテキスト形式で、画像などのバイナリファイルは含まれていません。

## Edge への読み込み

1. Edge で `edge://extensions/` を開きます。
2. 左側の **開発者モード** をオンにします。
3. **展開して読み込み** をクリックし、このフォルダーを選択します。
4. ツールバーの拡張機能一覧から **Quick Calculator** を開きます。

## キーボード操作

- 数字、`.`、`+`、`-`、`*`、`/`、`%`
- `Enter` または `=`: 計算
- `Backspace`: 1文字削除
- `Delete`: CE
- `Escape`: C
